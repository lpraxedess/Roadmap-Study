# Roadmap-Study

Meu planejamento de estudo com foco em Segurança da Informação e carreira em IAM.

## 🛡️ Laboratório IAM

Manual prático e detalhado para construir o laboratório de IAM com Active Directory, Microsoft Entra ID, Azure RBAC, MFA, Conditional Access, PIM, JIT, JEA, auditoria, PowerShell, Microsoft Graph, identidade híbrida e SIEM.

👉 [Abrir o Manual Completo do Laboratório IAM](docs/IAM-LAB-MANUAL.md)

## Estrutura

- `docs/IAM-LAB-MANUAL.md` — manual principal do laboratório
- `powershell/` — scripts de automação que serão desenvolvidos durante os exercícios
- `evidencias/` — evidências e documentação dos testes

## Princípio do laboratório

`Identidade → Autenticação → Autorização → Privilégio → Monitoramento → Revisão → Revogação`

O laboratório foi projetado para funcionar em uma máquina com recursos limitados, mantendo as VMs desligadas quando não forem necessárias.
