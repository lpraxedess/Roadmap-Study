## Padrão de evidência para novos projetos

**Problema → requisitos → arquitetura → implementação → testes positivos/negativos → logs → falhas → correções → custos → rollback → lições aprendidas.**

Nunca exponha informações pessoais ou segredos em screenshots, scripts ou configurações.
