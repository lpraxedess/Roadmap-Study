# IAM Study Lab

## Formação autoguiada em Identity & Access Management

**Aprender → implementar → validar → investigar → corrigir → documentar → projetar.**

Curso com base Microsoft Entra ID, AD DS e Azure, usando ferramentas abertas para que uma única licença Entra ID P2 e orçamento limitado não interrompam o aprendizado.

### Comece em 4 passos

1. Leia o [guia do aluno](guia-do-aluno.md) e faça o diagnóstico na [matriz](matriz-de-competencias.md).
2. Siga as [25 aulas estruturadas](curriculo.md), adiantando apenas as que demonstrar dominar.
3. Execute os [laboratórios](labs/01-keycloak-oidc.md) para comprovar conceitos e prática.
4. Produza os [seis projetos integradores](projetos/01-hybrid-recovery.md) e reúna evidências.

### Referências práticas

O [portfólio Projetos](https://github.com/lpraxedess/Projetos) registra implementações anteriores e permanece intocado. O [arquivo original com 32 módulos](https://github.com/lpraxedess/Roadmap-Study/blob/main/01-IAM/IAM-Study-Lab.md) é mantido integralmente como referência complementar durante evolução editorial.
