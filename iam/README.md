# IAM — Roadmap de estudos

**6 fases · 33 temas**

## Fase 1 — Identidades, Active Directory e Entra ID

1. Fundamentos de identidade, autenticação e autorização
2. Active Directory: objetos, OUs, grupos, LDAP e Kerberos
3. Microsoft Entra ID: usuários, grupos, roles e RBAC
4. RBAC, ABAC e princípio do menor privilégio
5. Identidade híbrida e sincronização AD–Entra
6. Joiner, Mover, Leaver (JML)

## Fase 2 — SSO e protocolos de identidade

1. Single Sign-On (SSO) e federação
2. OAuth 2.0 e OpenID Connect (OIDC)
3. SAML 2.0
4. SCIM 2.0 e provisionamento
5. Autenticação multifator (MFA), Passwordless, FIDO2 e Passkeys
6. Microsoft Entra Conditional Access
7. App Registrations, Enterprise Applications e Service Principals

## Fase 3 — Automação de IAM

1. Microsoft Graph API
2. PowerShell para IAM
3. Python e APIs REST

## Fase 4 — Governança e privilégios

1. Identity Governance and Administration (IGA)
2. Access Reviews e recertificação
3. Privileged Identity Management (PIM)
4. Privileged Access Management (PAM)
5. Secrets e Workload Identity
6. Entitlement Management e Access Packages
7. Identidades externas: B2B e convidados

## Fase 5 — IAM em nuvem e segurança

1. Azure IAM, RBAC e Managed Identity
2. IAM multicloud (AWS e Azure)
3. Identity Threat Detection and Response (ITDR)
4. Logs e troubleshooting de identidade
5. Zero Trust e acesso adaptativo
6. Microsoft Entra ID Protection

## Fase 6 — Engenharia e arquitetura

1. Infrastructure as Code (IaC), Git e CI/CD para IAM
2. Auditoria, controles e indicadores de IAM
3. Arquitetura IAM empresarial
4. Resiliência IAM e contas de emergência (Break Glass)
