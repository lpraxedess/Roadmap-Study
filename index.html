Memória: reserve 6–8 GB para o host, 2–3 GB para AD DS e 2–3 GB para Ubuntu Server (Keycloak dentro dessa VM, ajustando recursos conforme o uso). São estimativas, não requisitos mínimos oficiais.

Ordem: 1. Entra ID Free → 2. AD existente → 3. Ubuntu + Keycloak → 4. Syncope ou JumpServer, um por vez → 5. Intune/PIM somente com licença ou avaliação confirmada.

Controle de custo: a versão gratuita do Entra não inclui todos os recursos. PIM, acesso condicional, governança avançada e Intune podem exigir licenças específicas. Não ative trials sem verificar data de término, elegibilidade e cobrança.

Boas práticas: snapshots antes de alterar AD; dados fictícios; backups; desligar VMs e containers não usados; não confundir recurso equivalente open source com o mesmo produto Microsoft.
